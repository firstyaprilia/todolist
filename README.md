# Daftar Tugas Harian

## Deskripsi
Website sederhana berbasis PHP untuk mencatat dan mengelola tugas harian.

## Fitur
- Menambahkan tugas baru
- Menentukan tanggal tugas
- Menampilkan daftar tugas
- Mengubah nama dan tanggal tugas
- Menandai tugas selesai atau belum selesai
- Menghapus tugas

## Struktur Folder
- `index.php` - Halaman utama dan kode program
- `README.md` - Dokumentasi proyek

## Teknologi
- PHP
- HTML
- Bootstrap 5

## Cara Menjalankan
1. Pastikan XAMPP sudah terpasang.
2. Salin folder proyek ke folder `htdocs`.
3. Jalankan Apache melalui XAMPP.
4. Buka browser dan akses `http://localhost/todolist/index.php/`.
